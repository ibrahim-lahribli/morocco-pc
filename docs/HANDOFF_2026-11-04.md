## 3. Decisions that must not be re-litigated

1. **`TRUST_PROXY` stays empty on Render** (Decision 64). `trustProxy: true` and hop counts are both
   rejected: Render appends to whatever `X-Forwarded-For` the client sent, so either form lets one
   caller mint its own rate-limit bucket. The evidence that the safe half holds: two forged `XFF`
   values on the live host consumed one bucket, `x-ratelimit-remaining` 119 -> 118 **[measured
   2026-11-03]**. Limits are 30/min (POST), 30/min (swap commit and preview), 120/min (GET).
2. **A zero-build pass is not a preset** (R-26). Two keys at 6 000 MAD committed a pass whose every
   build was rejected; the endpoint advertised a page answering `builds: []`. They are removed, not
   shipped.
3. **A named write target needs a digest proof and a restore point.** A variable NAME proves nothing
   about what it points at, which is the case the digest check exists to catch.
4. **The identity gate skips on a fork PR.** That is a documented weakness, not an oversight: a green
   `unit-and-docs` from an outside contribution is not evidence the catalogue was checked.

## 6. Traps this session paid for

1. **A patch that writes one file then throws leaves a HALF-APPLIED change, and the `git commit`
   after it does not know.** Two commits here were amended for exactly that. Assert the anchor count,
   then read stderr - the shell's exit status is not the patch's.
2. **Replacing wrapped prose joins lines.** A regex anchored across a line break in `AGENTS.md`
   produced one 300-character line and a trailing space. Anchor inside one physical line, or re-wrap
   after.
3. **`str.replace` on a CRLF doc needs the EOL in the anchor.** Anchors ending in a bare `\n` match
   nothing in `docs/**` and `AGENTS.md`.
4. **Node's `/tmp` and Git Bash's `/tmp` are different directories on this box.** Write temp scripts
   into the repo root and delete them, or `bash` will not find what `node` wrote.
5. **6 000 MAD is inside the zero-build band** (cheapest real build ~7 877). Any fixture that expects
   builds must sit clearly above it, or it silently tests the empty path.
6. **`test:api:db` is the only suite that would have caught the preset regression**, and it is
   nightly-only - which is the argument for R-21 in one sentence.
